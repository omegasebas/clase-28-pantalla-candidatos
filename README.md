# clase-28-pantalla-candidatos
# Plataforma Juvenil de Participación

Proyecto académico desarrollado en el programa Programadores para la Paz.

## Clase 28 - Pantalla de candidatos o perfiles

En esta actividad se construye una pantalla visual de perfiles ficticios utilizando HTML, CSS y JavaScript.

Objetivo:

- Organizar información mediante tarjetas visuales.
- Presentar perfiles ficticios con fines pedagógicos.
- Mantener separación entre estructura HTML y diseño CSS.
- Aplicar interacción básica mediante JavaScript.
- Proteger datos personales evitando información real.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Archivos del proyecto

### index.html

Contiene la estructura principal de la página y las tarjetas de perfiles.

### styles.css

Contiene estilos visuales y organización gráfica de la interfaz.

### app.js

Contiene la interacción para mostrar información adicional de perfiles.

## Características implementadas

- Tarjetas visuales de perfiles
- Diseño responsivo básico
- Información ficticia pedagógica
- Organización visual mediante CSS
- Interacción básica con botones

## Importante

Este proyecto:

- No corresponde a una elección real.
- No utiliza datos personales reales.
- No registra votos.
- No genera resultados.
- No almacena información.

Proyecto académico desarrollado con fines educativos.
